## 更新内容

- 使用上游 0.2.6 的整个游戏界面与模块化代码，包括大厅、房间、干员调配、战场、统计、设置和多语言页面。

- 保留六人同盟、快速匹配、公开房间、聊天及管理后台；新增入口沿用新版视觉风格。
- 保留终极联防叠层：固定终极难度，联防获得的永久层数在结算后保留。

- 保留中日语音、证件照、皮肤选择和皮肤配置导入导出；皮肤信息传递到战斗与旁观渲染。
- 保留信标对自选协防的限制、归溟幽灵鲨替身倒计时、阿戈尔死亡顺序与自定义技能范围触发；攻击动画采用上游新版逐次攻击实现。
- 工坊可从大厅进入：编辑双方单位、属性、技能、盟约与波次，本地保存、导入导出、试战。

## 明确保留的边界

- 遵守 `.agents/rules/upstream-sync.md`，排除盟约收起/展开按钮。
- 工坊目录收录 2181 个敌人、2445 个变体；收录不代表每个 Wiki 特殊机制都已实现。工坊仍显示机制覆盖状态。
- 工坊独立编辑器为中文；游戏主体使用上游语言包。
- Android 的离线运行、远程服务器连接源码和原生运行库保留。本次没有生成 APK 或进行真机验证。升级后的页面建议使用已更新的 Android System WebView，原生启动器对低于 Chromium 100 的版本提示更新；旧 Chromium 80 的兼容承诺不再适用于此版。
- 原先 `public/shared`、`public/sim`、`public/data` 的代码副本改由 Node 静态映射提供，避免不同版本互相覆盖。纯静态站点需要先按新版部署工具生成资源，不能直接沿用旧副本。
- 旧版本的预加载及网络实现由上游资源管理/重连逻辑取代；旧实现专用断言以新版对应测试为准。
- 管理后台需要设置 `ADMIN_SECRET`；不再提供内置默认口令。

## 本地启动

桌面/服务器需要 Node.js 22 或更高版本。Android 随附的旧 Node 18 原生库尚未升级，后续 APK 发布前需要单独验证其运行兼容性。首次安装执行 `npm ci`，随后 `npm start`。
页面：`http://127.0.0.1:3000/?board=3d`；工坊：`http://127.0.0.1:3000/workshop/index.html`。
已有素材保留在 `public/assets`。补充素材使用 `node tools/fetch-assets.mjs --add-only`，维护分支皮肤可使用 `tools/build-skins.mjs` 等原工具。合并旧清单使用 `tools/merge-installed-assets.mjs`，避免旧语音格式覆盖新版。

## 创意工坊界面与编辑流程（2026-10-14）

- 使用与 v0.2.6 一致的深色、薄荷绿界面，新增分区导航、配置数量概览和双方素材缩略图；图片缺失时仍能编辑和试战。
- 敌人目录按 80 项分页，可搜索名称或编号、筛选机制实现状态；不再只显示前 400 个匹配项。没有实际属性的自选占位条目不进入干员选择列表。
- 波次支持复制、按出场时间排序和时间轴预览，显示数量与路线。最后出场超过试战时限时以橙色标示；仍允许用户设计有意截断的试战。
- 新建、读取和导入替换未保存配置前提示；关闭页面时使用浏览器的未保存提醒。原配置版本 1、浏览器保存位置和 JSON 格式保持兼容。
- 试战期间编辑配置会提示重新运行以应用；新增返回配置预览，结束或未开始时禁用暂停。工坊只运行本地模拟，不连接正式联机房间。
- 本轮验证：8 项工坊逻辑测试及 1 项真实 Edge 浏览器流程测试通过，定向 ESLint 无报错；浏览器流程包含保存、导入导出、非法配置拒绝、分页、复制排序、未保存保护、试战和 390 像素窄屏检查。
